CHALLENGES & RISKS → HOW WE OVERCOME THEM
ChallengeStrategy
Tamil speech errorsAccents, noise, Tamil-English mix
Confidence check + ask again; answer choices & ranges; tap/type backup
Scheme rules changeNo official public API
Curated rule catalog, updated from the cloud without an app update; official link on every card
OCR mistakesBlurry or old documents
User confirms every OCR field; unsure fields highlighted; photo retake tips
Privacy of personal dataAadhaar, income, family
Encrypted on the phone; masked Aadhaar; photos deleted; consent screen (DPDP Act 2023)
Govt portalsCaptcha, OTP, page changes
User solves captcha/OTP; app fills the rest; filled PDF as fallback
User trustFear of scams
Always free; “Not an official app” disclaimer; never asks for money or OTP
